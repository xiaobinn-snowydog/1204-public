# 1204 计划

一个人被冲动和环境推着走的时候，怎样停一下，看清身体、钱包和关系，再决定下一步？

1204 计划从这个问题开始。我在做一个社会实验：用几个真实项目，验证普通人在 AI 时代怎样还能把日子过好、过得幸福。

正在做的三件事：

- **丹灵**：开进社区的中医诊所，从疼痛和睡眠做起。
- **恒忆社**：替人长期寄存记忆，从旧物做起。
- **草台班子**：把经营自己的人生做成一个游戏。

三个都在早期。会改，也可能停。
